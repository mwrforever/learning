# 跨平台Markdown编辑器设计文档

**日期**: 2026-05-14  
**项目**: Typora风格跨平台Markdown编辑器  
**技术栈**: Tauri + Rust + React + Monaco Editor + Marked.js

## 概述

构建一个跨平台桌面应用，复刻Typora的Markdown编辑功能，支持HTML渲染、源码查看/编辑、自动保存，以及常用快捷键。

## 需求

### 功能需求

- **跨平台支持**: Windows、macOS、Linux
- **Markdown编辑**: 类似Typora的单栏所见即所得编辑体验
- **HTML支持**: 支持Markdown和HTML混合编辑，两者都能正确渲染
- **源码模式**: 可切换视图查看和编辑原始Markdown/HTML源码
- **自动保存**: 每次编辑后立即自动保存
- **快捷键**: 支持常用Markdown快捷键和编辑操作快捷键
- **文件格式**: 支持.md和.html文件

### 非功能需求

- **性能**: 流畅的编辑体验，支持大文件
- **可靠性**: 自动保存机制，防止数据丢失
- **安全性**: 防止XSS攻击，安全的HTML渲染
- **可维护性**: 清晰的架构，模块化设计

## 核心组件

### 编辑器组件

**Monaco Editor实例**:
- 配置为Markdown模式
- 实时语法高亮
- 自动补全
- 代码折叠
- 支持HTML标签的语法高亮

**功能**:
- 内容编辑
- 光标管理
- 选择操作
- 撤销/重做

### 渲染引擎

**Marked.js处理**:
- Markdown到HTML的转换
- 自定义渲染器支持HTML标签透传
- 双向绑定：编辑内容实时渲染

**渲染模式**:
- 所见即所得模式：渲染后的内容（可编辑）
- 源码模式：原始Markdown/HTML代码
- 平滑切换，保持光标位置

### 视图切换器

**视图模式**:
- WYSIWYG模式：渲染视图
- 源码模式：代码视图
- 切换快捷键：Ctrl+`

**状态管理**:
- 保持编辑状态
- 同步光标位置
- 维护撤销历史

### 自动保存管理器

**保存机制**:
- 防抖：每次编辑后延迟500ms保存
- Rust后端监控文件变化，避免冲突
- 保存状态指示器（已保存/保存中/未保存）

**备份策略**:
- 每次保存前创建备份副本
- 保留最近5个备份版本
- 恢复机制

## 快捷键系统

### Markdown快捷键

- `Ctrl+B`: 加粗
- `Ctrl+I`: 斜体
- `Ctrl+K`: 链接
- `Ctrl+Shift+C`: 代码块
- `Ctrl+Shift+H`: 标题

### 编辑操作快捷键

- `Ctrl+S`: 手动保存
- `Ctrl+``: 切换视图
- `Ctrl+/`: 源码模式
- `Ctrl+Z`: 撤销
- `Ctrl+Y`: 重做

### 文件操作快捷键

- `Ctrl+N`: 新建文件
- `Ctrl+O`: 打开文件
- `Ctrl+W`: 关闭文件
- `Ctrl+Shift+S`: 另存为

### 实现方式

- 前端Monaco Editor内置快捷键处理
- Rust后端注册全局快捷键（系统级操作）
- 可配置的快捷键映射，支持自定义

## 数据流和文件管理

### 文件操作流程

**打开文件**:
1. 用户选择文件
2. Rust后端读取文件内容
3. 通过IPC传递给前端
4. Monaco Editor加载内容
5. 根据扩展名识别文件类型（.md或.html）

**编辑保存**:
1. 用户编辑内容
2. Monaco Editor触发onChange
3. 防抖500ms
4. 通过IPC发送到Rust后端
5. 写入文件
6. 更新保存状态指示器

**视图切换**:
1. 用户触发切换（快捷键或按钮）
2. 前端在渲染HTML和源码之间切换
3. 保持编辑状态和光标位置

### 文件格式

**支持格式**:
- `.md`: Markdown内容，支持内嵌HTML标签
- `.html`: 纯HTML内容，直接渲染

**文件识别**:
- 打开文件时根据扩展名自动识别类型
- `.md`文件使用Marked.js渲染
- `.html`文件直接显示（可选择源码模式）

**元数据**:
- 在同级目录创建`.metadata`文件
- 记录光标位置、视图模式、编辑历史

### 冲突处理

- 文件被外部修改时提示用户重新加载
- 保存失败时显示错误并保留未保存状态
- 提供合并冲突解决界面

## 错误处理

### 文件操作错误

**文件不存在**:
- 提示用户并允许创建新文件
- 提供模板选择

**权限不足**:
- 显示错误信息
- 建议用户检查权限
- 提供以管理员权限重试选项

**保存失败**:
- 保留未保存状态
- 显示重试按钮
- 提供另存为选项

### 渲染错误

**Markdown解析失败**:
- 显示原始内容
- 标记错误位置
- 提供修复建议

**HTML渲染问题**:
- 使用安全模式渲染
- 防止XSS攻击
- 显示警告信息

**损坏文件**:
- 尝试恢复备份
- 提示用户手动修复
- 提供恢复向导

### 系统错误

**内存不足**:
- 提示用户关闭其他文件
- 自动清理缓存
- 提供性能优化建议

**应用崩溃**:
- 自动恢复上次打开的文件
- 恢复光标位置
- 显示崩溃报告

## 风险和缓解

### 技术风险

**Monaco Editor性能**:
- 风险：大文件可能性能不佳
- 缓解：实现虚拟滚动，延迟渲染

**HTML渲染安全**:
- 风险：XSS攻击
- 缓解：使用DOMPurify进行HTML净化

**跨平台兼容性**:
- 风险：不同平台行为差异
- 缓解：充分测试，平台特定适配

### 项目风险

**开发时间**:
- 风险：功能复杂，开发周期长
- 缓解：分阶段实施，优先核心功能

**维护成本**:

- 缓解：模块化设计，清晰文档
